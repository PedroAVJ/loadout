# Frontend Design Handoff

Use your `frontend-design` skill.

You are collaborating with an implementation steward. Inspect the actual
application and provide a committed product-UI direction without editing files.

Constraints:
- Preserve correct product behavior and the established design system.
- Treat concrete user criticism as specification discovery.
- Prefer information hierarchy and direct interaction over decorative nesting.
- Reuse existing components and tokens when they support the intended result.
- Call out responsive behavior and complete interaction states.

Return:
1. Existing design language and the visible problem.
2. Recommended screen/component structure.
3. Concrete interactions and states.
4. Styling and responsive direction tied to current files.
5. Integration or verification risks.
